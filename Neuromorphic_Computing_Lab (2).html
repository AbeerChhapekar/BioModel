2. SNN Neuron Laboratory

This is a time-domain Leaky Integrate-and-Fire (LIF) simulation. It shows, millisecond by millisecond, how input changes membrane potential, how leakage pulls voltage back toward rest, how a threshold crossing creates a spike, and how the reset/refractory period prevents immediate refiring.

Watch the neuron compute

The LIF model is deliberately simple: it keeps a single membrane-voltage state and treats a spike as a discrete event. In the presentation, the LIF model is described as integrating weighted inputs over time with leakage and firing when the threshold is crossed. fileciteturn2file0L116-L129

What the simulator is calculating

dv/dt = −(v − vrest)/τ + R·I

The first term is the leak toward the resting potential; the input term pushes the membrane upward. In this teaching model, vrest = −70 mV, and a spike occurs when v ≥ threshold. After the spike, voltage resets to rest and the neuron stays refractory for the selected period.

What a spike actually means

A spike is treated here as an all-or-none event. Its height is not used to encode a continuous number; the simulation uses the occurrence and timing of spikes. The presentation explains that membrane potential carries incoming information, threshold crossing generates the spike, and the potential resets afterward. fileciteturn2file0L49-L58

Input current

Applies a continuous drive. More current makes the membrane rise faster and increases the chance of repeated firing.

Firing threshold

Sets the voltage level that must be crossed to emit a spike. A less negative threshold makes firing easier.

Membrane time constant

Controls how quickly the neuron leaks back toward rest. Larger τ means slower leakage and more temporal integration.

Refractory period

After a spike, the neuron cannot immediately fire again. A longer period creates more separation between spikes.

Simulation speed

Changes how quickly the demonstration advances in simulated time. It does not alter the neuron's equations.

Inject input spike

Adds a short-lived synaptic input pulse, demonstrating event-driven input even when the background current is low.

Step 1 ms

Advances the model by exactly 1 ms while paused. Use it to inspect the voltage response one tiny time step at a time.

Reset

Returns voltage, timers, spike count, input events and the trace to the initial state.
